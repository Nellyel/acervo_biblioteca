FEATURE 2 - VALIDAÇÃO DO ANO

Arquivo:
- acervo/forms.py

Import:
from datetime import date

Método:
clean_ano()

O que faz:
- pega o ano com self.cleaned_data.get('ano')
- compara com date.today().year
- se o ano for futuro: raise forms.ValidationError(...)
- se for válido: return ano

Por que clean_ano?
Porque a regra é específica para o campo "ano".

Por que não precisou de migration?
Porque não houve alteração no banco/model.
Só foi adicionada uma regra no formulário
